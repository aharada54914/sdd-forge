## Evidence Boundaries

TEST-002 must show execution, not only successful catalog loading. TEST-003 mutations run in isolated temporary fixture copies, not frozen/pending repository artifacts. Existing successful Core baseline is not Red evidence. TEST-004 cannot certify Windows Desktop from a Linux host or an injected payload. Missing supported-platform evidence remains visible for review and must use the existing platform CI route before claiming that platform verified.

TEST-005 deterministic completion validation proves only the assertion contract; the three interpretation cases in design.md#evidence-and-handoff are reviewed expected outcomes, not executed behavioral results. TEST-008 checks delivery readiness, not #600 grader performance. Retention remains Not evaluated until existing Horizon/Retention receives subsequent observations. No #601 acceptance check authorizes changing approvals or declaring formal gate success.
