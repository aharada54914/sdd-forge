## Coverage Notes

- TEST-001a through TEST-001h each inspect the listed consumer groups; an
  absent or multiply classified consumer is a failure.
- TEST-003a through TEST-003e are separate target fixtures, so aggregate
  coverage cannot hide an untested target.
- TEST-008a through TEST-008d separately cover UI optionality, local artifacts,
  unavailable-tool fallback, and file import. TEST-008e covers per-feature
  grant, transient decline/re-prompt, and not-permitted fallback; TEST-008f
  covers standing no-prompt and one-time record per feature/destination;
  TEST-008g covers off no-upload fallback and persistent not-permitted record.
  Each setting fixture changes the configured value between resolutions and
  asserts the current value is re-read. TEST-009a/009b separately assert
  no-upload/non-blocking outcomes for denial or not-permitted/off and tool
  unavailability.
- TEST-005 and TEST-006 are separate because no-context compatibility and
  enabled hybrid compatibility are independent migration paths.
- Provider simulated/real distinction (TEST-010) does not count as deployment
  verification; deployment and promotion remain out of scope.
