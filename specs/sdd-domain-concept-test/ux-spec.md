# UX: Feature Concept Test

Show the actual feature request, existing concept responsibilities and evidence,
then propose a classification. Ask the human to confirm same/different/undecided;
do not treat silence as confirmation. For non-FITS, explain proceed,
defer-to-domain-update, and rejected before recording the selected decision.
Changed inputs require a fresh proposal/confirmation. A defer returns to domain
authoring; a reject stops; invalid evidence describes what must be repaired.
