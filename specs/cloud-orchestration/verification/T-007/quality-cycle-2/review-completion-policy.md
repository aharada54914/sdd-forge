# Independent review completion boundary

The implementation report is a frozen pre-review snapshot. The current fresh reserved evaluator supplies the task's named independent reviewer verdict; root separately runs the formal deterministic checks and generates/validates the evidence bundle. After actual delivery, the canonical quality report and verification completion record bind the real run/session, exact inputs and result. They supersede the handoff pending-review statement only when that result is PASS and required checks succeed. No future verdict is asserted, no old report is rewritten, and no additional approval explicitly required by a task is waived. This follows root AGENTS.md's frozen-artifact/addendum rule. Live OQ-001 remains blocking for affected tasks and is never satisfied by local test success.
