# Final author admission and public evidence boundary

The immutable author admission manifests record the actual allowed input paths and hashes, including private review-only delivery inputs and earlier author/controller/candidate records. Their payloads are not distributed in this public commit. These manifests are provenance for the actual author delivery; they are not claimed to form a fully public, clone-only reproducible author input bundle.

The independent evaluator receives the necessary original private input closure through a separately scoped, hash-bound delivery. Private identity ledgers, evaluator reservations, credentials, provider sessions and raw native model sessions remain excluded from public staging. A manifest's reference to a private review-only input is not permission to publish that payload.

The public acceptance/output evidence is a distinct, complete closure: original exact-F local sharded receipts, original hosted run/receipt and comparison records, actual annotated-tag publication, installed-payload audit, final report/contract, author admission/receipt chain and actual verification records. Reversible envelopes preserve original Windows receipt/log hashes where normal Git text normalization would otherwise change bytes; original private raw logs and archive objects remain available through their explicit path/hash indexes for independent review.

Preserved intermediate author outputs and failed or superseded check receipts describe their actual historical state. Only the final corrected report/contract and actual subsequent review can establish the final verdict. No reviewer reservation or quality PASS is asserted by this publication boundary note.
