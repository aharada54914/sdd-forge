# Fixed blinded semantic judge protocol v1

This is an optional judgment protocol, not a new rubric, candidate experiment or acceptance condition. Original model rubric and frozen skill v1/v3/v5 criteria remain authoritative. No actual judgment is collected here. Preserve every deterministic failure. Unknown actual backend identity is not itself a new criterion: apply the original proof requirement and judge whether identity claims accurately state its limits.

Use four **fresh, isolated configured gpt-6-astra/high contexts**: implementation (all four Harbor submissions), review (four Orchard plus four Meadow), investigation (all four Willow), skill command-plan (four Cedar/Maple using v5 whole-source bindings). No context resumes or shares another domain's transcript. All submissions within a domain receive the same judge brief, rubric, output schema and settings. Keep source/input/output hashes, requested/configured model/effort, actual reported IDs if any, scoped reroutes and actual usage in controller evidence. Configured model is not actual backend attestation; absent attestation remains unverified. Do not substitute a judge if unavailable.

Root first performs Harbor safety review, then the isolated frozen scorer with --reviewed-harbor. That review authorizes source execution only; semantic comparison goes to the blinded judge. For each domain, assemble the supplied-input schema from actual final submitted artifacts/answers, exact corresponding initial fixture files, original rubric and applicable frozen skill rubrics, actual deterministic receipt and sanitized controller observations. Judge receives line-preserving text under relative paths only. No self-reported test result is a deterministic receipt.

Assign opaque random stable submission/fixture IDs once, preserve them across receipt/input/output references, and shuffle input ordering once before judging. Root retains a separate private map to model, repetition, case/version, raw output hash and actual run path. That map, native event logs, model/repetition/variant labels, source directory names and labels in filenames are **not judge inputs**. Do not give the judge this notes file, root-private-map.template.json or model-arm configs. Frozen rubric prose may name the experiment's models, but never connects a submitted ID to a model. Preserve raw original artifacts privately. Avoid substantive redaction; if an answer contains identity-only metadata, retain the raw hash and a separately hashed, line-preserving identity-redacted judge copy with a private redaction log. If functional content cannot be blinded, report compromised blindness instead of claiming a blind judgment.

No new runner is needed. Reuse the public Client JSONRPC transport pattern already pinned in executor-preparation-v3, with one owned app-server per domain and the same public feature disables. Prepare these protocol messages only after T-008 Done and actual candidate outputs/scoring exist:

```
initialize: {clientInfo:{name:"semantic_judge",version:"1"},capabilities:{experimentalApi:true}}
initialized: {}
thread/start: {model:"gpt-6-astra",cwd:"<fresh ordinary judge project>",ephemeral:true,approvalPolicy:"never",sandbox:"read-only",allowProviderModelFallback:false,dynamicTools:[],config:{model_reasoning_effort:"high"}}
turn/start: {threadId:"<returned thread ID>",model:"gpt-6-astra",effort:"high",cwd:"<same project>",input:[{type:"text",text:"<exact brief.txt followed by exact assembled blinded input JSON>"}],outputSchema:<exact response.schema.json>}
```

The judge project contains only the assembled blinded bundle, schemas and brief; all evidence can be in the text, so no tool call is needed or authorized. Native builtin exclusivity is not assumed; unexpected tool requests/calls become a failed judge observation, not a silent success. Use the same fixed 300-second/24-call outer recording limits for all four contexts; exhaustion means judgment unavailable/failed, never waived candidate failure. Do not execute these commands or collect native judgments during preparation.

Validate returned IDs against the input bundle, criterion quotes against the actual frozen rubric, and every path/line/quote against actual supplied documents. Satisfied=true requires concrete evidence and uncertain=false. Judge cannot waive a deterministic failure or turn unknown evidence into fact. Material-regression entries are directional artifact differences between opaque IDs under comparable task contracts; they are not model winners or aesthetic judgments. Root reveals its private mapping only after preserving the judge output/hash, then applies the original both-repetition promotion rule. Preserve missing/invalid judgments, uncertainty and residual model/self-preference bias.
