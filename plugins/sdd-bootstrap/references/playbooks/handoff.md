# Handoff

Delegate to `investigate-codebase` read-only and preserve existing investigation
and implementation report handoff fields. Record objective, current feature/task,
fixed input hashes, commands actually run, results, pending decisions and the next
bounded action. Reference original logs and existing run records rather than
copying their verdicts. Do not infer Done from a summary or reconstruct a hidden
conversation/WAL. Keep unavailable facts explicitly unknown. Stop at the time/run
budget; resume by rechecking current inputs and existing authority.
