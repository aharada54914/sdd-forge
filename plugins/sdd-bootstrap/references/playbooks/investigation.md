# Investigation

Use `investigate-codebase`; retain its managed allocation and read-only tool boundary.
Inputs: objective, scenario, constraints, hypotheses, selection criteria and a
time/run budget. Trace entry points, actual callers, configuration and failure
paths. Test the one or two assumptions on which correctness depends using an
existing harmless command or fixture. Keep writes out of the target repository.
Evidence: source paths/lines, command/exit, known facts versus inferences and
unresolved questions. Stop at the budget, a write boundary or sufficient evidence.
Return the existing investigation/handoff formats; implementation returns to
bootstrap specification and the existing task approval path.
