## Summary

Implemented bounded POSIX panelist execution for the GPT and Gemini runners.
Both validate `SDD_PANELIST_TIMEOUT` before invoking a vendor CLI, default it
to 600 seconds when unset or empty, run the vendor in a dedicated process
group, and terminate that group with SIGTERM followed by SIGKILL after a
two-second grace period. Timeout remains a vendor failure (exit 1) and cannot
write a verdict; invalid configuration is a caller/tool error (exit 2). The
integer-second deadline includes the current fractional-second interval so the
configured budget cannot fire early.
