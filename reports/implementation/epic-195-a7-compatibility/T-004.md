## Summary

Implemented the offline structural-compatibility gate for the F1 full track and
F2 lite track in Bash and PowerShell. The suites derive their path sets,
template structure, status names, schema, refresh procedure, and anchor digest
from independent shipped/specification surfaces; they do not embed copied
expected document bodies. F3/F4/F5/F6 are recorded as the required named
dependency skips.

The Markdown canonicalizer twins hard-fail malformed frontmatter and
unrecognized heading grammar, sort frontmatter keys, preserve heading
level/order significance, normalize only permitted whitespace/line endings,
and compare corpus artifact arrays in ordinal path order. Both suites run fully
offline and fail from an empty product root.

Quality-gate cycle 1 remediation makes the PowerShell twin capture and require
the canonicalizer's exit status before comparing AST text. A coherent malformed
corpus/template mutation now hard-fails in both runtimes instead of allowing
two empty parse results to compare equal.

The required malformed-corpus RED was recorded before that fix: Bash killed
the case while PowerShell falsely survived at 40/0, producing 115 killed / 1
survived and harness exit 1. After the fix, every assertion family is
mutation-proved in both runtimes: 116 mutations killed, 0 survived, followed
by restored 40/0 GREEN runs. The mutation classifier now strips ANSI control
sequences and compacts wrapped diagnostics; independent violations of either
operation fail before restoration. Real depth-1 and unchanged
`scripts/bump-version.sh` replay proofs also pass. An independent reviewer and
independent tester both returned scoped PASS/APPROVED. This report does not
claim the formal SDD quality-gate or a Done transition.
