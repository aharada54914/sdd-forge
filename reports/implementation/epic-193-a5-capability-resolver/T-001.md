(`tests/resolver-evidence-schema-check.py`) — implements only the keyword
subset this one schema uses (`type`, `enum`, `const`, `pattern`, `minItems`,

`items`, local `$ref`, `if`/`then`, `not`), matching investigation.md
INV-011's no-third-party-dependency constraint. No equivalent
`validate-facet-manifest.py`-shaped precedent exists on this branch to
reuse — confirmed at implementation-start time that Epic A1/A2/A3/A4 have
not landed here (no `canonicalize-sdd-yaml`, `evaluate-predicate`,
`resolve-component-paths`, or any `validate-*.py` script exists under
`plugins/sdd-quality-loop/scripts/`), which is expected and harmless for
this task specifically: T-001's own `Depends On: none` and its own Scope
state every fixture is a hand-crafted instance validated directly against
this task's own schema document, never a live invocation.

Authored the twin suite `tests/resolver-evidence-schema.tests.sh`/`.ps1`
(TEST-017/018/019/020): schema existence + JSON validity + `$schema`
draft-07 + `$id` convention (TEST-017); 4 hand-crafted valid fixtures and 8
