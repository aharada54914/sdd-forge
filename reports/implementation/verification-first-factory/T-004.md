## REQ-007・REQ-008 の実装

`npm ci --prefix plugins/sdd-quality-loop/rules` で固定版の ast-grep を導入する。CLI は JavaScript、JSX、TypeScript、TSX の構文木を解析する。同じブロック内で同じ複数のフラグを組み合わせる条件、制御構造の深さ、抑止ディレクティブ、相対 import の循環を検出する。期限付き waiver と修正ヒントは既存 JSON 契約で返す。計算したモジュール名や TypeScript の tsconfig パス別名は循環検査の対象外。

`--diff-only --base-ref <commit>` は基準コミットと作業ツリーの差分から変更後の行範囲を読み、未追跡ファイルを新規として含める。CI は取得済みの PR の merge base または push 前の SHA を渡す。指定された ref を読めない場合は終了 2。相対 import の先にある未変更ファイルは循環判定のために読む。指摘は変更側の import 行に付く。`--files` 単独で明示ファイル全体を検査し、`--diff-only` を併用すると指定ファイルと変更行の交差を検査する。
