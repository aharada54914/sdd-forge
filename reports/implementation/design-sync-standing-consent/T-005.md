## Specification Differences

None affecting any Done-When criterion. Two implementation judgment calls,
disclosed for reviewer awareness since `tasks.md`'s Done-When did not
literally dictate either:

1. **Exact step names and insertion point.** `tasks.md` requires "one new
   step per OS-matrix leg ... following the live file's own existing
   step-naming and `if:` convention" but does not name the steps literally
   or state exactly where in the `test` job's step list they go. This task
   named them `Test design-sync-standing-consent suite (pwsh)`/`(bash)`
   (mirroring the closest existing sibling pair's shape,
   `Test Phase 2 guard invariants (pwsh)`/`(bash)`) and inserted them
   immediately before `Upload test logs` (mirroring
   `epic-136-phase3/verification/T-003/build-candidate.py`'s own insertion
   point for its new steps). `TEST-054`'s own check is name- and
   position-agnostic (it scans every `*.yml`/`*.yaml` under
   `.github/workflows/` for the two literal suite-path substrings), so
   neither choice is test-load-bearing.
2. **`TEST-054` GREEN evidence via a byte-verified standalone harness,
   rather than running the registered suite against a full sandboxed
   repository copy.** The registered suite derives `$ROOT`/`$repositoryRoot`
   from its own script location with no environment-variable override, so
   demonstrating it against the candidate without applying the candidate to
   the live path would require copying the entire working tree into a
   scratch sandbox. This task instead extracted and byte-verified only the
   `TEST-054` check logic itself (see Isolation Evidence), the narrower and
   lower-risk approach for a single-row, name-agnostic check. `tasks.md`'s
   Done-When says `TEST-054, run against the staged draft candidate ...
   is demonstrated in the implementation report to pass` without mandating
   the registered suite's own binary be the thing invoked; this task reads
   that as satisfied by a verified-identical extraction, flagged here for
   the quality gate to confirm that reading.
