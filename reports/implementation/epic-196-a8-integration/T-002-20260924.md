## Scope

Implemented a read-only installed-plugin drift checker with a Python master and
thin POSIX/PowerShell wrappers. The checker compares the tracked `plugins/**`
surface, Codex agent TOML files, and installer-owned MCP blocks in
`config.toml`. It emits `installed-plugin-drift-report/v1`, distinguishes
`preflight` from `verify`, reports added/removed/modified/type-changed entries,
and exits non-zero for detected drift without writing any input tree.
