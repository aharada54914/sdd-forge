## The Major -- and the in-gate fix applied

`tests/sdd-domain/contract-v2-schema.Tests.ps1:1907-1913`. AC-025 part (a)
requires a structural assertion that the term link's pattern **is identical to**
the concept id's pattern -- acceptance-tests.md:34 states it as "その pattern が
concept id と同一であることを構造 assertion で確認し". The test asserted
resemblance to a hardcoded literal and never read the concept-id declaration at
all, using Pester 4's case-insensitive `Should Be` on a case-carrying regex.

Two drifts passed undetected, measured in a mirror tree rather than argued:

| Drift | Before the fix | After the fix |
|---|---|---|
| A -- widen `concepts[].id` to `^CONCEPT-[A-Za-z0-9_]*$`, leaving `terms[].concept_id` alone | 318 passed / 1 failed, **byte-identical to the control**; zero checks fired | 4 passed / **1 failed** |
| B -- case-invert `terms[].concept_id` to `^concept-[a-z][a-z0-9-]*$` | 15 passed / 0 failed | 4 passed / **1 failed** |
| Control -- pristine schema | passes | 5 passed / 0 failed |

Drift A is the one that matters: with the two declarations diverged, a
schema-conformant contract can declare a concept id that no term may legally
reference, and nothing in the feature notices. T-001's line 122 carries the
identical weakness, so no other test closes it.

The Pester semantics the finding rests on were verified directly, not assumed:

```
[+] Should Be is case-insensitive
[-] Should BeExactly is case-sensitive
```

**Fix applied in-gate** under `auto-fix-policy.md` "missing tests for clear
requirements" -- the acceptance criterion is unambiguous and the test simply
asserted something weaker. The assertion now compares the two declarations with
`-ceq` and additionally pins the shared value with `BeExactly`, so a coordinated
drift of both declarations is caught as well as a divergent one. No requirement
was changed and no fixture was touched.

The suite total stays at 319 because an existing `It` was strengthened rather
than a new one added. That preserves T-005's allocation invariants -- the
78-fixture parity corpus and the 73 negative fixtures are untouched.

This fix must be reviewed by a fresh cycle; it is not self-certifying. The bytes
it produced are declared under `## Post-Fix Artifacts` below.
