# Fresh held-out native cohort

Two new controls were frozen at `b45eb529` before any candidate output:
`bundled-audit-readiness` derives from the real failed dependency-bundle parity
run; `cancelled-result-fencing` derives from the actual cancelled/restarted
Actions jobs and their preserved artifacts. The public output grammar and
private expected results were fixed before collection. No instructions, rubric,
inputs or case labels were changed from these candidate outcomes.

Twelve native Codex CLI 0.159.2 trials used the same `gpt-6.1-sol` model, low
effort, isolated tools, natural requests and fixed input per pair, with three
repetitions and alternating A/B order. A is main `0535c3c1`; B is `b45eb529`.
Both scored **6/6**, including all three repetitions of each case. All actual
trials completed within the frozen time budgets. Their median durations were
25.035 s and 19.860 s; token usage is retained and currency is unavailable.
The identical outcome does not establish framework superiority, stable p95,
retention or generalization from two cases. These cases are now exposed for
future work and must not be reused as unseen inputs after tuning.

The private rubric/map and repository remained outside the candidate mount/PID
namespace. Every project, actual native trace, stderr, protocol, config and case
snapshot is archived with hashes; profiles and credentials are excluded.
The grader also rejects deliberately wrong outputs in its existing registered
19-test suite. Neither the synthetic controls nor these model outputs issue
approval, update product state or replace the independent gate. Automatic
adoption remains disabled and the human decision remains pending.

The separate failed v1 (6/15 each) and public-contract epoch (15/15 each) are
preserved unchanged. Combining their counts into one success percentage would
mix input epochs and is not a valid estimate.
