## The Five Majors

1. **A test that passes with no repository present.** `retrospective-loop.
   tests.sh:164-283` is offered as the fixture-backed remediation of a prior
   Major. Its `root` is the test's own `mktemp -d`; it never opens the SKILL,
   the template, or any repo path. The evaluator extracted lines 55-283 into
   a standalone script and ran it **in an empty directory with no repository
   at all**: `ok: retrospective fixture derives exact counts 3/2/2/2`, exit
   0. The test writes its own fixtures, re-implements the algorithm inline,
   and asserts its own output equals a hardcoded constant. Three further
   probes confirm it: swapping 42 lines of pinned literals in the real
   artifacts kept it green, and appending rules that INVERT the documented
   selection/de-dup algorithm also kept it green. Rated Major not Critical
   because design.md scopes the deliverable to Markdown templates, so
   string-presence is legitimate for what exists — the defect is the report's
   claim that determinism was validated.
2. **No `red.log`.** Required Workflow is acceptance-first; the verification
   directory holds only `green.log`. Siblings T-002/003/004/005 each have
   both. With no captured red phase, nothing distinguishes assertions written
   before implementation from assertions written to match what already
   passed — which bites hard given finding 1.
3. **green.log is hand-composed narration.** Line 15 records
   `COMMAND: git diff --check -- <T-006 allowed tracked outputs>` — an
   unexpanded placeholder, never executed as written. Lines 2/4/6 record
   `RESULT: PASS` for `bash -n` invocations, which print nothing on success.
   Not wholly fabricated (lines 12-13 reproduce byte-identically today), but
   the unreproducible portions sit at ladder rung 5. `check-placeholders.sh`
   cannot catch this: a probe file containing that exact line passed.
4. **No `## Outputs` section.** Declarations exist only as
   `## Output Paths And Hashes` bullets. Measured `grep -c '^## Outputs'`:
   T-001..T-005 = 1 each, **T-006 = 0**. Commit `7f0f273b` added these
   appendices to T-001..T-004 and skipped T-006. The 10-entry manifest was
   therefore authorized from a serialization no validator parses. (It worked

5. **Done-When 1-3 unverifiable.** TEST-004 binds to
