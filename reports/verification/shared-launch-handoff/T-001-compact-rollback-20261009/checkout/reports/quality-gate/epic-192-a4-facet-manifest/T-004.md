   would show" was unguarded.

   fail-open, which is the precise failure class this comparator exists to
   prevent. `schema` and `feature` had been deliberately restored to the
   semantic set by an earlier adversarial review (requirements.md:353-362),
   making their lack of coverage worse than incidental.
3. **The sibling import was not fail-closed.** A missing or broken
   `validate-facet-manifest.py` raised at module top level, producing exit 1
   — which the contract fixes as `stale` — plus a multi-line traceback, so a
   broken install masqueraded as a real verdict on a channel design.md says
   callers may branch on alone.
