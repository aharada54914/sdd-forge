## Specification Differences

independent quality-gate's fix cycles:

- The cycle-1 Critical (WaitForExit(Int32) overflow above 2147483 seconds,
  which skipped Kill and orphaned the vendor process tree) is now handled
  by CLAMPING the wait milliseconds to [int]::MaxValue for larger values
  rather than by rejecting them: `$panelistWaitMs = if ($PanelistTimeout
  -gt $PanelistTimeoutMaximum) { [int]::MaxValue } else { $PanelistTimeout
  * 1000 }`. AC-003's accepted domain (every positive whole number) and its
  seven sub-cases are therefore unchanged; a transient exit-2 rejection of
  large values added by the first fix cycle was removed as an unauthorized
  contract narrowing. A regression case asserts a huge value (99999999) no
  longer throws and still invokes the CLI.

  1000)` pattern; the shipped code differs by the clamp above. Recorded
  here as a known-stale design line rather than amending the review-frozen
  design document for a Minor.
