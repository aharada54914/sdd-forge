# 今日のタスク

ローカルの単一ユーザー向け日本語タスクボードです。タイトルの追加、完了・未完了の切替、確認付き削除に対応し、JSON ファイルへ保存します。Python 標準ライブラリとブラウザーの HTML/CSS/JavaScript で動作します。

## 起動

この README のあるディレクトリで実行します。検証環境は Python 3.12 と Chromium です。

```bash
python3 server.py
```

表示された `http://127.0.0.1:8000` をブラウザーで開きます。終了は端末で `Ctrl+C`。ポートが使用中なら、別のポートを指定できます。

```bash
python3 server.py --port 8001
```

待受アドレスは常に `127.0.0.1` です。`--port 0` は空いているポートを選び、実際の URL を端末へ表示します。

## 使い方と保存先

「新しいタスク」に入力し、「追加」または Enter で保存します。タイトルの前後の空白は除去され、空白だけの入力は保存できません。上限は Unicode コードポイント 500 文字です。絵文字もこの単位で数えます。

チェックボックスで完了・未完了を切り替えます。「削除」は確認画面で確定した場合だけ反映されます。Tab で操作を移動し、Space でチェックを切り替えられます。保存中は更新操作が無効になります。

既定の保存先はプロジェクト直下の `data/tasks.json` です。ファイルがない場合は空で始まり、最初の保存時に作成されます。保存形式は `{"version":1,"tasks":[...]}` で、各タスクは `id`、`title`、`completed` を持ちます。保存先を変更する場合は次のように指定します。相対パスは起動したディレクトリが基準です。

```bash
python3 server.py --data-file ./data/personal-tasks.json
```

同じ保存先で再起動すると保存済みの状態が復元されます。

## 失敗時の確認と復旧

保存に失敗すると日本語のエラーが表示され、入力は保持されます。書込みは自動再送されません。応答だけが失われて保存済みの場合もあるため、再読み込みで状態を確認してから操作してください。通信は約 10 秒でタイムアウトします。

JSON が破損している場合はエラーとなり、自動で空データに置き換えません。復旧は次の順に行います。

1. `Ctrl+C` でサーバーを停止します。
2. 現在の JSON を別名でコピーして保管します。エラー原因や必要なデータを確認するまで削除しないでください。
3. 保存先ディレクトリの権限・空き容量を確認します。破損時は保管したファイルを残したまま、正常なバックアップから保存先へ復元します。
4. 同じ `--data-file` で再起動し、画面を再読み込みして状態を確認します。

バックアップもサーバーを停止してから手動でコピーします。ソースを以前の検証済み版に戻す場合も、先に停止し JSON を保管してから復元・再起動してください。自動バックアップやデータ移行はありません。

## テスト

ストレージ、HTTP、デザイントークンのテストは標準ライブラリのみで実行できます。テスト用の一時データを使い、通常の `data/tasks.json` は使用しません。

```bash
python3 -m unittest discover -s tests -v
```

ブラウザーテストには開発・検証用の Playwright と Chromium が必要です。アプリの実行時依存ではありません。検証済みの組合せは実行証跡に記録されています。必要なら仮想環境を作成し、Playwright を導入します。

```bash
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install playwright
```

Chromium を OS の方法で用意し、実行ファイルを指定します。次の出力先は未作成のディレクトリにしてください。再実行時には末尾の名前を変更します。

```bash
python3 tests/browser_checks.py --chromium /usr/bin/chromium --output-dir reports/visual-evidence/manual-run-01
```

ハーネスは一時保存先と実サーバーを用意し、終了時に停止します。結果 JSON、サーバーログ、スクリーンショットを指定先へ保存します。`--full` を追加すると標準ライブラリのテストも実行します。ブラウザーの一時ディレクトリは通常の短い `/tmp` を使用してください。非常に長い `TMPDIR` は Chromium のソケット作成に失敗することがあります。

最終受け入れ確認の記録は [T-005 レポート](reports/implementation/task-board/T-005.md)、[受け入れ結果表](reports/implementation/task-board/T-005/acceptance-results.md) を参照してください。拡大表示の証跡は CSS `zoom: 2` の確認であり、ブラウザーのメニューによるネイティブ拡大操作は実施していません。

## 制約

単一マシン・単一サーバープロセス・単一ユーザー向けです。同じ JSON に複数プロセスから書き込まないでください。通常のプロセス再起動後の保存を検証していますが、電源断時の耐久性は保証しません。

認証や暗号化はなく、JSON はローカルの平文です。Host/Origin と入力の検証を行いますが、同じマシンの別プロセスに対する認証はありません。ネットワーク公開、共有、クラウド同期は対象外です。編集・期日・検索・フィルター機能はありません。変更要求の本文上限は 64 KiB です。
