# Native reduced-stage diagnostic

Thirty authenticated Codex CLI 0.159.2 trials ran on Linux with
`gpt-6.1-sol`, low effort, three repetitions per case and revision, alternating
A/B then B/A. A is main `0535c3c1`; B is `4271e1c5`. The fixed source stage text
and equal reduced-task adaptation are pinned in the archive. This is a
stage-context comparison, not a full installed-plugin lifecycle or human UX test.

The collector froze protocol/case/input/config digests before collection.
Only each synthetic project, native profile, binaries and system libraries were
mounted in the candidate's filesystem/PID namespace. The private rubric, trial
map, host repository and collector directory were absent. Tools used native
workspace-write restrictions; no approval bypass was requested. The namespace
precheck confirmed the host fixture/rubric paths were absent. Profile directories
and credentials are excluded from the archived evidence.

All 30 final-setup trials completed. Exact deterministic grading: **6/15 on each
side**, neither all-success. Median total trial duration was 19.133 s for A and
17.027 s for B; no causal speedup or quality advantage is established. Routing
and cleanup each passed 3/3 on both sides. Audit status, plan limitations and
stale-skill reconciliation each failed the exact output contract 3/3 on each.
The original results remain failed, `mechanical_criteria_satisfied: false`, and
`adoption_eligible: false`; the result was frozen before reporting A/B identities.

Artifact inspection found a test-design defect: the natural requests did not
publish the exact enum/wording required by the hidden grader. Examples include
`partial` versus `incomplete`, descriptive human reconciliation versus the exact
`human-reconciliation` token, and truthful bounded-check limitations versus one
fixed sentence. These are evidence about this diagnostic, not blanket semantic
passes or grounds to weaken the grader. Public output grammars are added in a
separate case revision; a rerun is a new experiment and cannot retroactively
change these scores. All five original cases have now been exposed, including
the original two held-out cases. Later runs cannot establish unseen performance.

`raw-evidence.zip` retains each project, trace, stderr, source configs, initial
protocol, identity map and original case files. It also retains preliminary
infrastructure attempts: the first setup could not mount the native binary into
a read-only system directory; the second omitted Codex's code-mode helper and
was interrupted. No valid model comparison is attributed to those setups.
Hashes and byte counts are in `archive-index.json`. Currency was unavailable
from the native subscription; available turn token usage remains in each row.

The scripts record this specific experiment with fixed paths. A reproduction
must use new output directories and the recorded source/case revisions; it must
not overwrite this packet or substitute current case files when replaying v1.
