追加するSQL開発契約案は次のとおりです。

| 項目 | 契約案 |
|---|---|
| 環境・管理主体 | MySQL 8.4.0、ローカル専用の破棄可能DB。migrationはFlyway 13.12.1と`db/migrations`のみで管理 |
| スキーマ変更 | nullableな最大100文字の`note`を追加。既存行の`id`・`amount_cents`を保持し、既存行の`note`はNULL。backfill・旧列撤去なし |

| 互換性 | 旧アプリの読み書きと新アプリの検索を検証。旧アプリからの新規注文登録で`note`を省略可能にする |
| データ | 合成注文100件、PIIなし。整数主キーの一意性と非負整数の金額制約を保持 |
| 性能 | 改善要求なし。性能比較・高速化の主張は対象外 |
| トラック | Lite候補。隔離・合成データ・共有利用者なし・限定的変更という条件に基づく。確定はbootstrapの既存判定に従う |
