# 観測基盤 第3段階・環境別常駐の検証

ユーザー指示に従い、外部常設ホストを要求する設計を撤回。各ローカル・隔離環境で
独立する常駐サービスを同梱し、この環境でも起動・実動作確認した。
開始時の親サービスが表示先を選ぶ（ChatGPT → Sites、Claude → Artifacts）方針は維持。
子エージェントのモデル・サービスは選択に影響しない。

## 実装

- `dashboard-runtime.py start/status/stop`：OSユーザー・実プロジェクトパス・ホスト名ごとに
  状態を分離。多重起動をロックで抑止。ループバックの認証付き制御口、5秒ごとの死活監視、
  子プロセス再起動、起動コードの指紋による旧版置換。プラグインの表示開始・再開時に起動する。
- `publish`：既存非公開Sitesの認証情報を隠したstdinからメモリ内で受け取り、送信プロセスも監督。
  認証・データ拒否の終了78では設定修正待ち。秘密を引数・状態ファイル・公開コードに保存しない。
- 第3段階：変更履歴、画面内通知、確認済み状態、連続観測した滞留時間、開発テーマの日本語メタデータ。
  このプロジェクトの48名称は `dashboard-labels.json`。他の導入先に既定値として配布しない。
- Sitesはスナップショットと派生履歴を同じ条件付きR2書き込みで確定。ローカルはPythonが派生状態を
  原子的に保存し、Node MCP本体のファイル書き込み禁止契約を維持する。
- 正本、Approval、Status、品質ゲート、エビデンスの変更は行わない。

## 保証範囲

OS/コンテナ停止中は観測できない。次の親プラグイン呼び出しで起動し直す仕様であり、OSブート時の
サービス登録ではない。永続ボリュームを消去すればローカル履歴も失われる。ホームとホスト名を共有する
隔離環境は別のXDG_STATE_HOMEを使う。Sitesの認証は監督プロセスの終了で失われるため、再開時に
親サービスから再接続する。停止中は公開画面に古さが表示される。

履歴は観測時刻であり、操作時刻・操作者を推測しない。滞留時間は最後の正常観測まで。
200件・30日の論理保持で、期限切れデータの物理削除は次の保存時。ローカルチェックポイントの間隔は
5秒のため、クラッシュ直前の未保存の観測を失う場合がある。監査証跡やワークフロー正本ではない。

Linux環境で検証。Windows/macOS実機、OS再起動、スクリーンリーダー、アクセシビリティ全面適合は
未検証。今回はSitesを選択して公開した。ClaudeのネイティブArtifacts公開・接続同意は未実施で、
スナップショットのみのMCP接続では履歴未提供を明示する。Artifactsアダプター試験を実サービスの
検証とは数えない。カバレッジ率の計測と追加lintは行っていない。
