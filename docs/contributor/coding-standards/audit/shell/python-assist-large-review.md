## Resolver

The restricted YAML reader uses an ordinal mapping, rejects unsupported YAML constructs and tab indentation, preserves empty sequences, and checks trailing content. It is deliberately not a full YAML implementation. Consumers validate component/path/shared-path shapes before the literal glob compiler. The review found that `if` pipeline unrolling and parameter coercion could turn array/mapping IDs or array shared fields into strings: four actual malformed documents were admitted. The repair preserves the raw field value and checks string type before lookup or normalization. This is a consumer-schema finding under CS-004, not a change to the supported YAML language.

Glob compilation escapes every literal character and expands only supported stars. Segment recursion advances indices and memoizes results; NFC collision checks use ordinal raw identity. Classification preserves shared priority, exclusion evidence, distinct component case, raw UTF-8 sort and stable tie order. Digest serialization delegates to the existing finite local canonicalizer with a checked result and finally cleanup; no new CLI dependency or timeout was imposed on that regular-file computation. Schema conformance retains its explicit bounded draft-07 subset and its documented scalar-as-string parser convention, and reports a failure diagnostic for divergent artifacts.

Git parsing preserves NUL framing and strict UTF-8 paths, checks diff/rename-limit/merge-base results, and retries an inconsistent snapshot once. The missed `git status` result check was a real fail-open snapshot defect and is now repaired. `Invoke-GitRaw` wraps shared mechanism failures in its existing `GitDiffError`. The shared helper supplies separate argv atoms, reads stdout/stderr concurrently as bytes, applies the existing 30-second Git inspection deadline to process and stream completion, and owns cancellation, termination and stream/process disposal. Actual sleeping executable evidence proves direct-child termination on this Linux host. The mechanism attempts tree kill where the runtime supports it and uses direct-child kill otherwise; it does not establish a universal descendant guarantee after a parent has exited or across native Windows/macOS.

Advisory provider diagnosis is not an Implementation Gate. Its component-to-path map nevertheless must preserve component identity: a real A/a fixture previously falsely joined lower/file to A. The map now uses ordinal keys. Provider text explicitly uses UTF-8. Optional absence remains an explicit N/A warning, not a successful gate receipt. No process result or failure-path suppression was introduced to make malformed configuration appear valid.

## Panelist input

Arguments arrive as data; no eval/Invoke-Expression is used. Consent is evaluated before reading review content. Task-section and human-flag matching now preserve exact protocol spelling, and signed token repository binding uses exact comparison. Existing key precedence remains unchanged: an explicitly named unreadable key does not fall back; absence of a key denies consent. The signature-skip fixture remains explicit test mode, not evidence of real signature validation. A separate final regression signs both correct and incorrectly cased repository bindings with the existing fixture signing helper, accepting only the correct binding. This review does not claim constant-time comparison beyond the existing documented implementation.

Literal path handling now reaches consent/input reads, project-root resolution, implementation-report reads and output writes. Existing plain-file input previously selected a wildcard sibling; a historical-source replay with direct argv isolates that production defect from the test driver's own wildcard expansion. The existing test invocation helper now uses `ProcessStartInfo.ArgumentList`, so its bracket-path control actually reaches the child unchanged rather than being expanded by the parent PowerShell host. No new test runner or suite was added.

Directory composition retains fixed spec documents, task-owned evidence, explicit contract evidence, implementation report and declared outputs. Discovered evidence symbolic-link files are excluded, matching the ordinary-file inventory intent; an actual outside sentinel was previously included. Declared output paths still reject absolute/backslash/dot segments and walk components for symlinks before a read. Optional absent/malformed contract metadata remains a tolerant reader rather than a replacement for the contract gate. Required Outputs rows retain unparseable-row failure and current-content/stale/missing distinctions.

Declaration-commit lookup now uses the same bounded raw Git mechanism. Parsed-row fingerprints still identify the oldest consecutive matching Outputs section; historical fallback still verifies the declared hash before acceptance. Historical blob verification hashes raw captured bytes directly, removing dependence on native stdout text redirection and its temporary file. Nonzero lookup/show results preserve conservative no-history/no-match behavior, and a timeout does not create an accepted declaration.

Sanitization retains explicit credential/path/private-URL patterns, UTF-8 digesting and a visible sanitization notice. It is a set of specified redaction controls, not a claim to identify every possible secret. The two-tier budget loop is finite over inventoried files, recalculates actual serialized bytes, marks elisions and refuses output if the requested budget still cannot be met. Per-invocation caches and mutable lists are local to one build; no request-spanning authorization state was added.
